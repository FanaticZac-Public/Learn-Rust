Note:
- In cargo, projects(aka crates):
    - you are only allowed 1 library (/src/lib.rs) file
    - you can have as many bin files, the default is /src/main.js
        - But you can have as many as you want in /src/bin/any-name.rs
- So with workspace - I should be able to use binaries from other crates and reduce size for the section of my Learn-Rust project.

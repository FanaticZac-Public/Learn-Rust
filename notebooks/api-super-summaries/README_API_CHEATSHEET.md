# API - Super Summaries

I generated these just to give me a quick summary of methods available to the primary classes. 

While doing leet code examples (and trying to avoid looking at AI solutions) - it became frustrating to slowly look at the documentation for some method that would accomplish the job. Rusts makes it is easy to daisy chain functions - and often I'd miss a very useful function that would make my code way easier - Now I can just check these for primary method first - and memorize - get the right tool for the job.

They're not all inclusive - many have traits that can employ their own methods. But it's a running start for building the mental toolkit when writing in Rust. 

I'll did most of the main ones for std library Modules/Structs in the [Rust Prelude](https://doc.rust-lang.org/beta/std/prelude/index.html)
